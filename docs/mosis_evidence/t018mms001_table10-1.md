# TSMC 0.18um 1P6M field stack — Table 10.1 of T-018-MM-SP-001

Evidence for the TSMC018 (T28M, DSCN6M018_TSMC) planned profile field stack.

Source: TSMC document `T-018-MM-SP-001` Ver. 1.3, "TSMC 0.18UM MIXED SIGNAL
1P6M SALICIDE 1.8V/3.3V RF SPICE MODELS", 2004 (TSMC-RESTRICTED).
Hosted by third parties: scribd doc 928142601; eetop/iczhiku mirror.
Nature: `official` content, `official-mirror` hosting (same class as the T27K
scribd mirror). Retrieved 2026-09-29 via scribd text extraction.

T28M (2001 MOSIS run) is DSCN6M018 — a 6-metal SCN018 scheme; this 2004 spec is
the closest official 6M stack and matches its sheet pattern (M1–M5 0.08,
M6 0.03 ohm/sq).

## Gaps

- Substrate resistivity not stated in the document. RF papers modeling TSMC
  0.18 um commonly use ~10 ohm-cm; treat as derived until a run-specific value
  is found.
- The 2007 IEEE MTT paper (dokumen.pub IEEE MTT-V055-I12) models a 0.18 um 1P6M
  stack as M1–M5 0.55 um / top 2.0 um, consistent with the above (0.53/2.34 um).
- T28M-era (2001) exact film values may differ slightly from the 2004 spec;
  both are 6-metal SCN018 schemes.
